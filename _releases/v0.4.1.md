## ⬆️ Improvements

### Release assets are attested from your release branch

Release assets were only attested on the release pull request, so anything that requires provenance from your release branch, such as a Homebrew tap that runs `gh attestation verify --source-ref refs/heads/main`, rejected them. Release Planner now also attests the files after publishing them, from the release branch, and starts downstream workflows only once that's done. Only files you approved and published get this attestation, so a tap can keep requiring it. See [release assets](https://release-planner.fabricahq.com/customize/release-assets/). (#25)
