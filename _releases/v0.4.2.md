## 🐛 Squashed Bugs

### Downstream workflows and the release branch attestation now run

When a release reused the files built on its release pull request, which is the usual case, the Release workflow skipped the `attest-release` and `downstream` jobs. The release published, but its files weren't attested from your release branch, and downstream workflows, such as a Homebrew tap update, never started. Both jobs now run after every release that publishes. Run `release-planner install` after upgrading to update your Release workflow. (#28)
