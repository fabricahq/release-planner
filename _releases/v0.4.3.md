## 🐛 Squashed Bugs

### Retry a release after upgrading Release Planner

A manual retry of the Release workflow failed right away if you had upgraded Release Planner since the release merged, because the release's merge commit still pinned the old version. Retries now run with the version your release branch pins today, so you can upgrade to pick up a fix and then retry the release. Run `release-planner install` after upgrading to update your Release workflow. (#30)
