## ⬆️ Improvements

### Release notes now focus more on what end users care about

We've updated default guidance to direct your agent to write release notes with more focus on what your readers get: what they can now do, what works better, and what they have to change. We also emphasized that technical details should be included only when readers need them to understand the value or act. If your own release notes style asks for more detail, the agent keeps it.
